# Nucleus

Nucleus is an experimental LCF-style kernel built around SQLite-backed protocol state.

To run the current signed, hash-selected HOL proof demo in either the terminal or a browser, see
[the hash-selected HOL quickstart](docs/hash-selected-hol-quickstart.md). To move a signed HOL
database between the terminal and browser REPLs, see the
[signed HOL file handoff](docs/signed-hol-file-handoff.md). The architectural direction and trust
boundaries are described in [the REPL architecture](docs/repl-architecture.md).
