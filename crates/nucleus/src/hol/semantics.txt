nucleus HOL-omega kernel-state semantics, version 1
===================================================

This file is the normative semantic commitment for the kernel-state schema.
hol_semantics_id() tags exactly these bytes; any change to this file is a
different schema identity. The reference calculus is the Lean ProjectBeth
HOL-omega development (imbrem/tekne.dev#2): raw syntax and syntax-directed
Kinded/HasType judgements (Defs/HOLOmega/Syntax.lean), substitution
(Substitution.lean), and the semantic kernel's EqTm/Derives rules with the
explicit universal type Ty.all (Kernel.lean). Design rationale:
https://gist.github.com/imbrem/138afa0af9a26bd2e284c932bcd63ce3

Identifiers
-----------
Object ids are positive 64-bit integers. Coordinate 0 means empty/absent.
Negative coordinates are reserved for designated-source namespace positions
(-n denotes position n-1 of the designated source) and are INVALID in
version 1. Every id-valued coordinate of a row must be smaller than the
row's own id (children precede parents; the object graph is acyclic by
construction). Hash-consing (the UNIQUE indexes) is a local optimization:
equal ids always denote equal syntax, but the semantics never assumes the
converse, and duplicate rows denote the same object.

Sorts and tags
--------------
Sort classes: kind {1,2}; type {3..11}; term {12..22}; kinds-spine {23};
vars-spine {24}; hyps-spine {25}. Unused slots must be 0.

Spines grow inward: the row is the innermost entry (index 0); parent 0 is
the empty spine. HS spines are canonical: each row's rhs is strictly
greater than its parent's rhs, giving sorted-set semantics.

The HOL fragment is tags {1,3,7,8,9,10,11,12,13,14,17,18,19,20,21,22} and
all K_STAR kinds; tags {2,4,5,6,15,16} are the omega layer. A fragment
database contains no omega tags.

Formation (kind_of over Delta; type_of over Delta; Gamma)
---------------------------------------------------------
kind_of (TY_BV n)        = Delta[n]
kind_of (TY_LAM K B)     = K_ARR(K, kind_of[K::Delta] B)
kind_of (TY_APP F X)     = L    if kind_of F = K_ARR(K, L) and kind_of X = K
kind_of (TY_ALL K B)     = K_STAR  if kind_of[K::Delta] B = K_STAR
kind_of TY_BOOL = kind_of TY_IND = kind_of (TY_EXT s p) = K_STAR
kind_of (TY_ARR A B)     = K_STAR  if both children have kind K_STAR
kind_of (TY_SUB A p)     = K_STAR  if kind_of A = K_STAR
                                   and type_of[Delta; [A]] p = TY_BOOL

type_of (TM_BV n)        = Gamma[n]
type_of (TM_APP f x)     = B    if type_of f = TY_ARR(A, B), type_of x = A
type_of (TM_LAM A t)     = TY_ARR(A, type_of[Delta; A::Gamma] t),
                                   kind_of A = K_STAR
type_of (TM_TYLAM K t)   = TY_ALL(K, A)
                           where A = type_of[K::Delta; liftTy Gamma] t
type_of (TM_TYAPP f X)   = instTy0(A, X)  if type_of f = TY_ALL(K, A)
                                          and kind_of X = K
type_of (TM_BOOL b)      = TY_BOOL
type_of (TM_EQ x y)      = TY_BOOL  if type_of x = type_of y
type_of (TM_EPS p)       = A    if type_of p = TY_ARR(A, TY_BOOL)
type_of (TM_ABS p x)     = TY_SUB(A, p)  where A = type_of x
                                          and type_of[Delta; [A]] p = TY_BOOL
type_of (TM_REP p x)     = A    if type_of x = TY_SUB(A, p)
type_of (TM_EXT s i T)   = T    if kind_of T = K_STAR

Type equality is structural; TY_EXT/TM_EXT leaves are equal exactly when
their (source_id, position) coordinates agree. Substitution and lifting are
the operations of Substitution.lean (capture-avoiding de Bruijn; memo keys
include every semantic parameter). TM_TYLAM deliberately requires the
lifted Gamma (the semantic kernel's Ctx.weaken), strictly stronger than the
raw Lean rule.

Theorems
--------
A theorem row (kinds, vars, hyps, concl) asserts Delta; Gamma; H |- p with
p of type TY_BOOL and every hypothesis of type TY_BOOL, all well-formed
under the row's spines. Soundness invariant: every hol_theorem row is
derivable by the rules below (or admitted through an explicit trusted
import). The invariant is preserved by arbitrary row deletion; theorem_id
is a handle, never authority.

Rules (23)
----------
Theta = (Delta; Gamma; H). "H,p" is canonical insertion; union is canonical
spine union and requires equal Delta; Gamma. All premises are revalidated
in-store; a failing step persists nothing.

ASSUME  (Delta,Gamma,p)      p : bool                  => Delta;Gamma;{p} |- p
WEAKEN_HYP (thm, q)          q : bool                  => H,q
WEAKEN_VAR (thm, A)          kind_of A = *             => Delta; A::Gamma; liftTm H |- liftTm p
WEAKEN_KIND (thm, K)                                   => K::Delta; liftTy Gamma; liftTy H |- liftTy p
INST_TM (thm, Gamma', ts)    |ts| = |Gamma|, ts_i : Gamma_i in (Delta;Gamma')
                                                       => Delta; Gamma'; H[s] |- p[s]
INST_TY (thm, Delta', Xs)    |Xs| = |Delta|, kind_of Xs_j = Delta_j in Delta'
                                                       => Delta'; Gamma[s]; H[s] |- p[s]
TRUTH   (Delta,Gamma)                                  => |- TM_BOOL 1
REFL    (Delta,Gamma,t)      t well-typed              => |- EQ t t
SYM     (prem)               prem: |- EQ x y           => Theta |- EQ y x
TRANS   (l, r)               l: |- EQ x y ; r: |- EQ y z
                                                       => H1 u H2 |- EQ x z
EQ_MP   (eq, prem)           eq: |- EQ p q ; prem: |- p => H1 u H2 |- q
MK_COMB (feq, aeq)           |- EQ f g at TY_ARR(A,B); |- EQ x y at A
                                                       => H1 u H2 |- EQ (APP f x) (APP g y)
ABS     (prem)               prem: Delta; A::Gamma; H |- EQ x y,
                             every h in H strengthens (h = liftTm h')
                                                       => Delta;Gamma;H' |- EQ (LAM A x) (LAM A y)
TY_ABS  (prem)               prem: K::Delta; liftTy Gamma'; H |- EQ x y,
                             every h strengthens over TY_BV 0
                                                       => Delta;Gamma';H' |- EQ (TYLAM K x) (TYLAM K y)
BETA    (Delta,Gamma,l,s)    l = LAM A t, s : A        => |- EQ (APP l s) (subst0 t s)
ETA     (Delta,Gamma,f)      f : TY_ARR(A,B)           => |- EQ (LAM A (APP liftTm(f) (BV 0))) f
TY_BETA (Delta,Gamma,l,X)    l = TYLAM K t, kind_of X = K
                                                       => |- EQ (TYAPP l X) (instTy0 t X)
TY_ETA  (Delta,Gamma,f)      f : TY_ALL(K,A)           => |- EQ (TYLAM K (TYAPP liftTy(f) (TY_BV 0))) f
CHOICE  (prem)               prem concl = APP p x      => Theta |- APP p (EPS p)
DEDUCT_ANTISYM (l, r)        l: |- p ; r: |- q         => (H1\{q}) u (H2\{p}) |- EQ p q
ABS_REP (Delta,Gamma,x)      x : TY_SUB(A,p)           => |- EQ (ABS p (REP p x)) x
REP_ABS (prem, p, x)         prem concl = subst0(p,x), x : A,
                             p : bool in (Delta;[A])   => Theta |- EQ (REP p (ABS p x)) x
INFINITY ()                                            => 0;0;0 |- INF

INFINITY's conclusion INF is the closed term built from these abbreviations
over primitive syntax (A ranges over types; x over terms):
  not t         := TM_EQ(t, TM_BOOL 0)
  and p q       := TM_EQ(TM_LAM(BB, APP(APP(BV 0, lift p), lift q)),
                         TM_LAM(BB, APP(APP(BV 0, TM_BOOL 1), TM_BOOL 1)))
                   where BB := bool -> bool -> bool
  forall A P    := TM_EQ(P, TM_LAM(A, TM_BOOL 1))     for P : A -> bool
  exists A P    := not (forall A (TM_LAM(A, not (TM_APP (lift P) (TM_BV 0)))))
  I             := TY_IND, II := TY_ARR(I, I)
  one_one f     := forall I (lam x1. forall I (lam x2.
                     TM_EQ(TM_EQ(APP f'' x1', APP f'' x2'), TM_EQ(x1', x2'))))
  onto f        := forall I (lam y. exists I (lam x. TM_EQ(y', APP f'' x')))
  INF           := exists II (lam f. and (one_one (BV 0)) (not (onto (BV 0))))
Primes mark the de Bruijn lifts required by binder depth; "lift" is liftTm
by one.
The exact interned tree is pinned by the fixed vector in the test suite.

SYM and TRANS are primitive: with equality as a node former rather than
a term constant, the HOL Light derivations of symmetry/transitivity from
MK_COMB do not apply (the reference EqTm likewise carries symm/trans as
constructors). Derived above the kernel (standard derivations recorded in
the design appendix): Leibniz eq-mp; congruence for the EQ, EPS, ABS, and
type-application formers via the lambda-wrapper trick over MK_COMB, BETA,
SYM, and TRANS; hypothesis alignment; and all propositional connectives
and quantifiers.

Rule failures leave no rows. Repeating a derivation whose conclusion row
exists returns the existing theorem_id where the local uniqueness index is
present; duplicates are semantically harmless.
