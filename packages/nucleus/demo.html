Content-addressed SQLite

A database is named by the hash of its bytes. The same design runs as a kernel inside this page and as a kernel you reach over HTTP.

1. A kernel in this page — wasm, no server

SQLite, a content-addressed store, and a VFS mounting one on the other, all compiled to wasm. Choose a .sqlite file: it is hashed, admitted, and opened by address. Nothing leaves the tab. 

Choose a file to begin.

2. A kernel over HTTP — another process, another origin

Start one with cargo run -p covalence-bin-cas-serve -- FILE.sqlite; it prints an address and a URL. The page fetches the object, checks it hashes to the address it asked for, and only then admits it. A wrong or hostile server is caught here rather than believed. 

Enter a kernel URL and an address.
